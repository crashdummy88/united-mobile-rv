Victron fault codes & field diagnostics

As a Victron Professional Certified Installer, we live in MultiPlus, Quattro, and SmartSolar systems daily. Read the alarm in VictronConnect or on the device first — then use this field guide. We do not guess codes from memory memes.

Field notes

Victron MultiPlus / MultiPlus-II / Quattro inverter-chargers and SmartSolar MPPTs report alarms differently (LEDs, VE.Bus reports, VictronConnect notifications, GX / VRM history). Your source of truth is the live reading plus the official manual for your exact model and firmware. Error/alarm classes are largely voltage-agnostic across 12V / 24V / 48V — but always match the manual for your SKU. Prefer Victron’s live wiki, manuals hub, and VictronConnect live docs — per current Victron doc for your firmware. United Mobile RV does not host .swu / .bin files.

How to confirm before you buy parts

  1. Open VictronConnect on the product (Bluetooth / VE.Direct as equipped).
  2. Note the exact alarm / error text or number — screenshot it.
  3. Cross-check the live wiki and manuals hub for that product — not a random forum paste.
  4. If GX-connected, check VRM alarm history for patterns (flapping vs one hard fault).
  5. Prefer Text the screenshot to UMRT before you order a new inverter.

Inverter-charger alarm classes we see most

Class-based on purpose — confirm the exact wording in VictronConnect or the device display. We do not invent Err SKU matrices here.

Low battery / under-voltage shutdown

Bank could not support the AC load — capacity, SoC lie (bad shunt path), undersized cable, BMS load disconnect, or a truly empty bank. Check resting vs loaded voltage at the inverter DC lugs (not only at the battery), lug torque, fuse, BMS state, and surge loads. Not automatically “buy a bigger Multi.”

Temperature / overtemp

Hot bay, blocked airflow, failed fan, or continuous load beyond thermal comfort. Clear ventilation, verify fan operation per manual, and respect summer derating.

Voltage ripple / high DC ripple

Poor DC connection quality or inadequate conductor — the inverter sees unstable DC under load. Loose lugs beat board replacement more often than people want to hear. Inspect/retorque battery, shunt, bus, and inverter DC connections; verify cable gauge and fuse hierarchy.

Overload / inrush shutdowns

AC load or surge exceeded capability — microwave + induction + compressor stories. Note what started at the trip; review PowerAssist / current-limit if shore-tied; never treat peak stickers as continuous.

VE.Bus / configuration symptoms

Settings, firmware mismatch, or VE.Bus link issues — not always silicon death. Use Victron tools from official software downloads only. UMRT does not host firmware binaries.

Confirm in-app

Whatever LED or Err number you see — match it to current Victron documentation for your firmware before replacing hardware.

SmartSolar / MPPT error classes

Publish exact Err numbers only after you read them in the app. Common classes owners hit:

Battery / voltage related

Battery sense or voltage outside the expected window. Confirm battery connected, sense wiring, and Li profile voltages vs BMS limits.

Remote / external control

Charger disabled by BMS / GX / remote (DVCC, allow-to-charge, cold inhibit). Looks like “MPPT dead” on a sunny day.

PV overvoltage class

Array Voc too high — especially cold mornings. String design vs MPPT max Voc.

Overtemp / derating

Hot controller, poor mounting, limited airflow, high current.

Internal / calibration class

Follow the official troubleshooting path in the manual — do not flash random files.

Update first

Before deep troubleshooting, update VictronConnect and controller firmware from official Victron sources — some reported errors were already fixed upstream.

Quirks that look like hardware failure

Phone / Bluetooth

OS Bluetooth and location permission rules blocking VictronConnect discovery. See software VictronConnect troubleshoot.

GX / VRM “dead”

Old GX firmware or offline Wi-Fi so VRM looks dead while the Multi is fine. Update via official Victron firmware paths only.

Cold-charge inhibit

BMS refused charge near freezing — not a failed MPPT. Confirm battery manual; heated packs differ.

Wrong shunt capacity

Bad capacity setting → panic SoC and mystery low-battery behavior.

DIY vs book UMRT

Reasonable DIY

Screenshot the alarm, retorque accessible lugs if you are competent and de-energized, verify remote/BMS allow-to-charge, read the live manual section for that alarm class.

FAQ

Are 12V / 24V / 48V codes different?

Alarm classes are largely shared; always confirm text and limits for your exact model and firmware. Do not scale 12V resting numbers blindly onto a 48V bank without the manual.

Will you send me a firmware file?

No. Firmware and tools come from Victron official sources only. We help you use them correctly — we do not redistribute binaries.

Is ripple always a bad inverter?

Usually connection quality or cable first. Meter and retorque before condemning the board.

Where is the software twin?
